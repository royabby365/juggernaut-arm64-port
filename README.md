This is a scaffold for rebuilding the decompiled game as a **64-bit (arm64-v8a)**
Android APK. The decompiled C# source has been dropped into `Assets/Scripts/`.

## Build steps (run in Unity Editor 2021.3 LTS on Win/Mac/Linux)
1. **Open** this folder as a project in Unity 2021.3.45f1.
2. Unity will reimport all scripts. Expect **compile errors** — that's expected.
3. **Fix the semantic sites** listed in `Assets/Scripts/SEMANTIC_FIXES.md`:
   - 21× `GetComponent("typename")` → `GetComponent<TypeName>()`
   - 37× bare UnityScript globals (`renderer.`, `animation.`, ...) → `GetComponent<T>()`
4. **Fix any remaining Unity 4.x API breakage** the compiler reports
   (WWW→UnityWebRequest, scene APIs, etc.).
5. **Reimport assets**: copy the original game's `assets/bin/Data/` (levels, prefabs,
   textures, audio) into `Assets/`. Unity's serialized format changed a lot since 4.x,
   so some assets may not load and need manual reconstruction.
6. **Verify Build Settings** (already pre-set in ProjectSettings.asset):
   - Platform: Android
   - Scripting Backend: **IL2CPP**
   - Target Architectures: **ARM64 (arm64-v8a)** ONLY (this is the 64-bit switch)
   - Min API 22, Target API 31
7. **Build** → `Build App Bundle` or `Build APK`. Sign with a keystore.
8. **Install on Pixel 10 Pro** (Android 16). It will now run as native 64-bit.

## What was already done (automated, safe)
**Mechanical pass (Option A):**
- `transform.active = X` → `transform.gameObject.SetActive(X)`  (10 files, 18 changes)
- `Application.LoadLevel(X)` → `SceneManager.LoadScene(X)` + `using UnityEngine.SceneManagement;`

**Semantic pass (type-resolved, 55 sites / 23 files):**
- 16× `GetComponent("typename")` → `GetComponent<TypeName>()` (resolved against 852 project types)
- 36× bare UnityScript globals (`renderer.`→`GetComponent<Renderer>()`, etc.) → `GetComponent<T>()`
- `MeshRenderer` built-in added to resolver
- Only 2 sites left unresolved: `GetComponent("character")` in `assets.cs:137,145`
  (ambiguous — `character` is a GameObject var, not a type; needs Editor-side decision)

**Backups:** originals in `decompiled/` as `*.bak` and `*.semfix.bak`.

## What CANNOT be done on the headless server (BigDeborah)
- No Unity Editor here → cannot compile-verify or produce an APK.
- Asset reimport + UnityScript semantics only validate inside a real Editor.
- The 64-bit `.so` engine files are regenerated by Unity at build time; the originals
  (32-bit) are discarded. No native code reverse-engineering required.
